Calculadora de IMC

Projeto desenvolvido em Python utilizando interface gráfica Tkinter e programação orientada a objetos.

O sistema permite cadastrar o nome e endereço do paciente, informar altura e peso e calcular automaticamente o Índice de Massa Corporal (IMC).

O resultado apresenta o valor calculado e sua classificação.

Funcionalidades

Cadastro do nome do paciente

Campo para endereço

Entrada de altura e peso

Cálculo automático do IMC

Classificação do resultado

Botões para calcular, reiniciar e sair

Tecnologia utilizada

Python

Tkinter

Programação Orientada a Objetos (POO)
